# Camera Tracking User Flow

## Flow 1 — Capture Photo

User membuka aplikasi

↓

Permission kamera diperiksa

↓

Camera Preview muncul

↓

User memilih mode:

* Photo
* Video
* Tracking
* Detection

↓

User mengatur zoom

↓

User menekan Capture

↓

Sistem:

* mengambil foto
* mengambil GPS
* menyimpan metadata

↓

Preview hasil

↓

Selesai

---

## Flow 2 — Object Tracking

User membuka mode Tracking

↓

Sistem menampilkan tracking overlay

↓

User memilih target

↓

AI mulai tracking

↓

Tracking Box muncul

↓

Metadata tersimpan

---

## Navigation Rules

Top Bar:

* GPS status
* Flash
* Settings

Bottom Bar:

* Gallery
* Capture
* Camera Switch

Tidak boleh:

* floating widget acak
* panel menutupi kamera
* tombol overlap
