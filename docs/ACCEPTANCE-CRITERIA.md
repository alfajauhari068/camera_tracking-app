# Camera Tracking Acceptance Criteria

## Camera Screen

AC-001

Ketika aplikasi dibuka:

Expected:

* Camera Preview muncul
* Tidak crash
* Loading < 2 detik

---

AC-002

Ketika user menekan Capture:

Expected:

* Foto tersimpan
* GPS tersimpan
* Timestamp tersimpan

---

AC-003

Ketika user menekan zoom:

Expected:

* Zoom slider muncul
* Slider dapat digunakan
* Slider menghilang otomatis setelah 5 detik

---

AC-004

Ketika user berpindah mode:

Expected:

* UI tidak overlap
* Tidak terjadi overflow
* Tidak terjadi freeze

---

AC-005

Expected:

* Tidak ada tombol yang tidak bisa ditekan
* Tidak ada widget yang menutupi tombol
* Tidak ada Stack conflict
